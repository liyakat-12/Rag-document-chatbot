# Evaluation corpus (public / reproducible)

Only documents that can be **committed** or fetched via `download_corpus.py` belong here.
Personal resumes and unclear-licence reports were removed in the Phase 1 fixes.

## Committed fixtures

| File | Purpose |
|------|---------|
| `policy_leave_entitlement.pdf` | Numbers, table, near-miss stipend |
| `invoice_fixture_q3.pdf` | Invoice totals, SKUs, Tesla near-miss |
| `api_error_codes.pdf` | Exact identifiers (DMAPI-*), HTTP near-miss |
| `smoke_ada2.pdf` | Tiny resume (Ada Lovelace) |
| `_smoke_perf.pdf` | Tiny resume (Grace Hopper) |
| `qa_design.pdf` | Hybrid / RRF fact |
| `scheme_amgf.pdf` / `_d` | Aurora Midcap Growth Fund SID (+ Direct) |
| `scheme_bfcf.pdf` / `_d` | Boreal Flexi Cap Fund SID (+ Direct) |
| `scheme_cldf.pdf` / `_d` | Cascade Low Duration Fund SID (+ Direct) |
| `circular_amc_disclosure_2024.pdf` | Synthetic AMC disclosure circular |
| `comparative_note_equity_schemes.pdf` | Long note (no numeric TERs) |

Synthetic scheme/circular/note fixtures are regenerated by `_gen_public_fixtures.py`
(invoked from `download_corpus.py`). Near-identical SIDs differ only in named fields
(TER, ISIN, AUM, manager, etc.) for disambiguation questions.

## Adding more public PDFs

1. Copy a redistributable PDF into this folder **or** add a URL to `download_corpus.py`.
2. Run `python evals/corpus/download_corpus.py` (also regenerates synthetic fixtures).
3. Regenerate the manifest if needed (download script already calls `write_manifest`).
4. Rebuild hard drafts via `evals/data/_rebuild_hard_questions.py`, then
   `python -m evals.difficulty` and `python -m evals.label` for verification.

## Isolated index

Evaluation builds FAISS+BM25 under `evals/.index/` (gitignored) from this folder only.
It never reads the app `vector_store/` or SQLite database.
